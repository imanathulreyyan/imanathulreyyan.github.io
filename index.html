Method

Every project ships with a cleaning log, a dashboard, and a README with findings and limitations, so the work can be checked.

  1. Clean

    Check blanks, duplicates and wrong data types, and record every fix in a cleaning log.

  2. Analyse

    Add helper columns, build pivot tables and compare rates, not just counts.

  3. Visualise

    One measure per chart, a heading that states the finding, and slicers to explore.

  4. Recommend

    End with a clear recommendation and honest limits: patterns, not proven causes.
