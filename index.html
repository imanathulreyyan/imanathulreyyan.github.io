How I work

The same four steps in every project

Every project ships with a Cleaning Log, a dashboard, a README with findings and a list of limitations, so the work can be checked.

01

Clean

Check blanks, duplicates and wrong data types, and record every fix in a Cleaning Log.

02

Analyse

Add helper columns, build pivot tables and compare rates, not just counts.

03

Visualise

One measure per chart, a heading that states the finding, and slicers to explore.

04

Recommend

End with a clear recommendation and honest limitations: patterns, not proven causes.
